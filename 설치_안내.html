설치 안내

참여 현황과 쿠폰 관리를 쓰려면 구글 스프레드시트를 서버로 연결해요. 처음 한 번만 하면 되고 20분쯤 걸려요. 서버 없이 쓰려면 2번 단계만 하면 돼요.

폴더에 있는 파일

파일하는 일
index.html학생용 문제 풀이 앱
admin.html관리자 모드 (참여 현황, 쿠폰 관리, 문제 수정, QR 인쇄, 초기화)
config.js서버 주소와 기본 문제
qr.jsQR 코드 만들기
Code.gs구글 시트 서버 코드 (인터넷에 올리지 않아요)

1. 구글 시트 서버 만들기

  1. 구글 드라이브에서 새 스프레드시트를 만들어요. 이름 예: 카페 WITH 관리
  2. 메뉴에서 확장 프로그램 → Apps Script를 눌러요.
  3. 편집기에 있는 내용을 모두 지우고 Code.gs 파일 내용을 붙여 넣은 뒤 저장해요.
  4. 위쪽의 함수 선택 칸에서 setup을 고르고 실행을 눌러요. 권한을 묻는 창이 나오면 내 계정을 고르고 허용해요. ‘확인되지 않은 앱’ 경고가 나오면 고급 → 이동을 누르면 돼요. 내가 만든 코드라서 괜찮아요.
  5. 스프레드시트로 돌아가면 설정 · 기록 · 쿠폰 탭이 생겨 있어요. 설정 탭의 adminPin(관리자 비밀번호, 처음 값 1234)을 꼭 바꿔 주세요.
  6. Apps Script에서 배포 → 새 배포를 누르고 유형을 웹 앱으로 골라요.
    • 다음 사용자 인증 정보로 실행: 나
    • 액세스 권한이 있는 사용자: 모든 사용자
  7. 배포를 누르면 나오는 웹 앱 URL(…/exec로 끝나는 주소)을 복사해요.
  8. config.js를 메모장으로 열어 apiUrl: ""의 따옴표 안에 복사한 주소를 붙여 넣고 저장해요.

학교 구글 계정에는 ‘모든 사용자’ 항목이 없을 수 있어요. 그럴 때는 개인 구글 계정으로 시트를 만들어 주세요.

2. 인터넷에 올리기

  1. index.html, admin.html, config.js, qr.js, 설치_안내.html을 Netlify나 GitHub Pages 같은 무료 호스팅에 올려요.
  2. 올린 뒤 받은 주소로 휴대폰에서 학생용 앱이 열리는지 확인해요.

3. 처음 설정하기

  1. 올린 주소 뒤에 admin.html을 붙여 관리자 모드를 열고, 바꾼 관리자 비밀번호로 들어가요.
  2. 문제 수정 탭에서 문제를 확인하고 서버에 저장을 한 번 눌러요. 저장하기 전에는 학생이 쿠폰을 받을 수 없어요.
  3. 같은 탭에서 바리스타 비밀번호도 정해요.
  4. QR 인쇄 탭에서 학생용 앱 주소를 확인하고 포스터를 인쇄해요.
  5. 휴대폰으로 미리 풀어 보고, 축제 전에 초기화 탭에서 테스트 기록을 지워요.

알아 두기

  • 문제와 쿠폰 기준은 관리자 모드에서 저장하면 바로 반영돼요. 문제를 새로 만들거나 지우면 QR 포스터를 다시 인쇄해 주세요.
  • 쿠폰은 서버가 맞힌 개수를 다시 확인한 뒤에 발급해요. 쿠폰 번호마다 한 번만 쓸 수 있어요.
  • 바리스타는 학생 휴대폰에 비밀번호를 누르거나, 관리자 모드의 쿠폰 관리에서 쿠폰 번호로 사용 처리할 수 있어요.
  • 인터넷이 잠깐 끊겨도 문제 결과는 휴대폰에 모아 두었다가 다시 연결되면 보내요.
  • Code.gs를 고친 뒤에는 배포 → 배포 관리 → 수정 → 새 버전으로 다시 배포해야 반영돼요. 주소는 바뀌지 않아요.
  • 시트를 직접 고치면 앱이 잘못 동작할 수 있어요. 비밀번호를 바꿀 때 말고는 관리자 모드를 써 주세요.
